# Giełda: praca skupu, prototyp

Trzy warianty panelu skupu używanego sprzętu z grupy na Facebooku (22.10.2026). To prototyp, nie działający panel.
Strona z opisem i porównaniem: `index.html`, makiety w pełnym rozmiarze: `A.html`, `B.html`, `C.html`.

Nazwiska sprzedawców i osób ze skupu są zastąpione. Zdjęcia sprzętu pochodzą z ogłoszeń na grupie.
Plików nie edytuje się ręcznie, buduje je `node makieta/wygoda2/gen.js --anon` w repozytorium roboczym.
